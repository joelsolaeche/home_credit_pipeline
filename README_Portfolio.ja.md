## 🎯 プロジェクト概要

本プロジェクトは、ホームクレジット社の**ローン債務不履行リスク予測**という重要なビジネス課題に取り組み、金融機関が情報に基づいた融資判断を行い、財務損失を削減し、顧客体験を向上させることを支援します。

### **ビジネス課題**
- **課題**: ローン申込者が返済を滞納するかどうかを予測
- **影響**: 不良債権による財務損失を削減しながら、信用へのアクセスを維持
- **評価指標**: 適合率と再現率のバランスを取るためのROC曲線下面積(AUC-ROC)
- **データ**: ホームクレジットの実際の申込から得られた122特徴量を持つ24.6万件以上の学習サンプル

### **主な成果**
- 🎯 最適化されたLightGBMモデルで**75.5%のAUC-ROC**を達成
- 🚀 生データから予測まで**完全自動化されたMLパイプライン**
- 📊 主要なビジネスインサイトを明らかにする**包括的な探索的データ解析**
- 🔧 モジュラーアーキテクチャによる**本番環境対応コード**
- ⚡ **複数モデルの比較**(ロジスティック回帰 → ランダムフォレスト → LightGBM)
- 🌐 ライブデモンストレーション用の**インタラクティブダッシュボード**を備えたプロフェッショナルなWebインターフェース
